- [ДЗ 2 — OpenAPI, CRUD и заказы](hw2/README.md)

Запускай команды из каталога нужного задания: `cd hw1`, `cd hw2` или `cd hw3`.

ДЗ 1 и ДЗ 2 по умолчанию используют порт 8000. Для одновременного запуска укажи другой порт у ДЗ 1: `PORT=8001 docker compose up --build -d --wait`.

ДЗ 3 запускается отдельным Docker-проектом и использует REST-порт 8003 и gRPC-порт 50051.
